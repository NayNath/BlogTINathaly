Dicas importantes

Ao escrever HTML, procure usar as tags de forma semântica, ou seja com sigificado. Evite usar apenas elementos visuais.

  • Use < strong > para dar importância
  • Use < em > para ênfase
  • Organize o conteúdo com listas
